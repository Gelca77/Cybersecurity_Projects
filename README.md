# Cybersecurity-Projects  

## Introduction  
This repository contains my beginner and intermediate projects in Cybersecurity.  
I am building hands-on experience in different areas of security, including:  
- Network traffic analysis  
- Intrusion detection rules  
- Cryptography basics   

My goal is to connect these technical skills with my long-term research interests in AI-driven, technical cybersecurity defenses for social engineering.  

## Projects  

### 1. Network Exploit Analysis and Snort Rule Development  
- **Goal:** Analyze recorded exploits using Wireshark and create Snort IDS rules to detect them.  
- **Techniques:** Packet capture analysis, signature rule writing.  
- **Exploits:** IRC Backdoor and GlassFish Deployer.  
- **Results:** Wrote Snort rules that flagged malicious traffic while minimizing false positives.  

### 2. OpenSSL Certificates Project  
- **Goal:** Explore the process of creating and managing certificates with OpenSSL.  
- **Techniques:** Generating keys, signing certificates, verifying certificate chains.  
- **Results:** Learned how certificates support encryption, authentication, and trust in secure systems.  

### 3. Python Cheating Hangman Project  
- **Goal:** A “cheating hangman” game to explore adversarial thinking.  
- **Techniques:** Implemented logic for dynamically shifting the target word to reduce predictability. 
- **Results:** Reinforced Python fundamentals while understanding deception in interactive systems
